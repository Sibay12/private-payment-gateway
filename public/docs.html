Private UPI Payment Gateway Integration Guide

इस डॉक्यूमेंटेशन की मदद से आप अपने टेलीग्राम बोट या किसी भी अन्य कस्टम वेबसाइट से इस यूपीआई गेटवे को आसानी से जोड़ सकते हैं।

Step 1: Server Deployment Setup (Render पर)

1. अपने प्रोजेक्ट को GitHub पर पुश करें।
2. Render पर Web Service बनाएं और Start Command में node server.js सेट करें।
3. आपका लाइव बेस यूआरएल मिल जाएगा (जैसे: https://your-app.onrender.com)।

API Endpoints & Usage

1. Create Payment Request (POST)

जब भी कोई यूजर टेलीग्राम बोट या वेबसाइट पर पेमेंट शुरू करे, तो अपने सर्वर से इस एपीआई को कॉल करें:

Endpoint: POST https://your-app.onrender.com/api/create-payment

Headers:

Content-Type: application/json
x-api-key: sibaditya_secure_api_key_2026

Request Body:

{
  "amount": 100,
  "orderId": "BOT_ORD_12345"
}

Response Example:

{
  "success": true,
  "orderId": "BOT_ORD_12345",
  "amount": 100,
  "qrCodeUrl": "data:image/png;base64,...",
  "checkoutUrl": "https://your-app.onrender.com/index.html?orderId=BOT_ORD_12345&amount=100"
}

2. Check Payment Status (GET - Polling for Telegram Bot)

टेलीग्राम बोट या चेकआउट पेज इस एंडपॉइंट को हर 4-5 सेकंड में हिट करके पेमेंट का स्टेटस चेक कर सकता है:

Endpoint: GET https://your-app.onrender.com/api/check-status/BOT_ORD_12345

Response Example:

{
  "success": true,
  "status": "SUCCESS", 
  "amount": 100,
  "orderId": "BOT_ORD_12345"
}

*(जब status में "SUCCESS" आ जाए, तो टेलीग्राम बोट यूजर को पेमेंट सफल होने का मैसेज भेज सकता है)*
