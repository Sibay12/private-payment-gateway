🚀 Private UPI Payment Gateway - API Docs

Welcome to the official API documentation for automated UPI payment integration. All requests require your secret API key.

Authentication

Pass your API key in the request header:

x-api-key: sibaditya_secure_api_key_2026

1. Create Payment

POST /api/create-payment

Generates a dynamic UPI QR code and checkout link for a given order.

Request Body (JSON):

{
    "amount": 10,
    "orderId": "ORD_123456"
}

Response:

{
    "success": true,
    "orderId": "ORD_123456",
    "amount": 10,
    "qrCodeUrl": "data:image/png;base64,...",
    "checkoutUrl": "https://your-app.onrender.com/index.html?orderId=ORD_123456&amount=10"
}

2. Check Payment Status

GET /api/check-status/:orderId

Verifies whether the payment for the specific order has been received via email automation.

Response:

{
    "success": true,
    "status": "SUCCESS", 
    "amount": 10,
    "orderId": "ORD_123456"
}

Note: Status can be either PENDING or SUCCESS.
