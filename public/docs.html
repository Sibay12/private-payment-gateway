🚀 UPI Payment Gateway API

Welcome to the official API documentation. Integrate automated UPI payments effortlessly into your applications.

Authentication

Include your secret API key in the request headers:

x-api-key: sibaditya_secure_api_key_2026

1. Create Payment & Generate QR

POST /api/create-payment

Generates a dynamic UPI QR code, checkout link, and mobile intent link.

Request Body (JSON):

{
    "amount": 10,
    "orderId": "ORD_998877"
}

Response:

{
    "success": true,
    "orderId": "ORD_998877",
    "amount": 10,
    "qrCodeUrl": "data:image/png;base64,...",
    "checkoutUrl": "https://your-app.onrender.com/index.html?orderId=ORD_998877&amount=10&redirectUrl=https://yourwebsite.com/success"
}

2. Check Payment Status

GET /api/check-status/:orderId

Verifies whether the payment has been completed and verified via email automation.

Response:

{
    "success": true,
    "status": "SUCCESS", 
    "amount": 10,
    "orderId": "ORD_998877"
}
